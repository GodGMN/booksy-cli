## `booksy appointment`

Your appointments: list, show, cancel, reschedule

## `booksy appointment cancel`

Cancel an appointment (asks first, or --yes)

```bash
booksy appointment cancel <uid> [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | bool | `false` | cancel without asking |

## `booksy appointment list`

Appointments on the account, newest first

```bash
booksy appointment list [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--limit` | int | `20` | at most this many (0 for all) |
| `--past` | bool | `false` | only finished, cancelled or missed appointments |
| `--upcoming` | bool | `false` | only appointments still ahead |

## `booksy appointment reschedule`

Move an appointment to another start time

```bash
booksy appointment reschedule <uid> [flags]
```

Move an appointment to another open start time, keeping its service and
staffer. Check times first with `booksy slots`. Asks first, or --yes.

```bash
booksy appointment reschedule 123456789 --at 2026-12-05T18:00 --dry-run
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--at` | string | - | new start time, 2026-12-05T18:00 (required) |
| `--dry-run` | bool | `false` | prepare and show the change, then stop |
| `--note` | string | - | replace the note for the business |
| `--yes` | bool | `false` | reschedule without asking |
