These pages are generated from the CLI's own command tree by `cmd/docsgen`, so they list exactly the flags the released binary accepts. `booksy <command> --help` shows the same thing offline.

Commands are nouns with verbs under them (`booksy watch add slots`). Every command takes the [global flags](/docs/reference/global-flags): `--format`, `--profile`, `--country`, `--error-format` and the rest.

For exit codes and the error envelope, see [troubleshooting](/docs/troubleshooting) and [scripts and AI agents](/docs/agents).
