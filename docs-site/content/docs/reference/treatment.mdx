## `booksy treatment`

Booksy's shared service catalogue (ids for earliest --treatment)

Each business names its services as it likes ("Arreglo de barba"), but every
service is filed under one of Booksy's catalogue treatments ("Recorte de la
barba", 71). Treatments are how one service is compared across businesses.

## `booksy treatment search`

Find treatments matching text, as the booksy.com search box does

```bash
booksy treatment search <text...>
```

```bash
booksy treatment search barba
```
