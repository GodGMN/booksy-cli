## `booksy sink`

Notification targets for watches (ntfy, webhook, exec)

Sinks are declared in config.toml, for example:

  [sinks.phone]
  type = "ntfy"
  url = "https://ntfy.sh"
  topic = "my-secret-topic"

  [sinks.discord]
  type = "webhook"
  url = "https://discord.com/api/webhooks/..."
  template = "discord"

  [sinks.script]
  type = "exec"
  command = ["~/bin/on-slot.sh"]   # gets the event JSON on stdin

or with `booksy config set sinks.phone.type ntfy` and friends.

## `booksy sink list`

Configured sinks

```bash
booksy sink list
```

## `booksy sink test`

Send a sample event to a sink

```bash
booksy sink test <name>
```
