## `booksy earliest`

Earliest open slots for one treatment across nearby businesses

```bash
booksy earliest [treatment text...] [flags]
```

Find the earliest open slots for one kind of service across many businesses.

Matching goes by Booksy's catalogue treatment, not by service names, which each
business picks itself: give --treatment ID (see `booksy treatment search`) or
text, which is resolved to the best treatment match. Businesses come from the
same search as `booksy search` (--near, --geo, else the profile location), nearest
first. Results are sorted by start time and carry the business and variant
ids to pass to `booksy book`.

Cancellation fees and prepayments only show at booking time: run
`booksy book ... --dry-run` on the pick before booking.

```bash
booksy earliest barba --near Valencia --when "mon-fri 16:00-close" --when sat
booksy earliest --treatment 71 --geo 39.47,-0.38 --days 21 --limit 5 --format pretty
booksy earliest "corte caballero" --near Madrid --when "weekdays 18:00-" --per-business 3
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--anywhere` | bool | `false` | ignore the profile's saved location and search the whole country |
| `--before` | string | - | only slots starting before this date or date and time |
| `--between` | string | - | only start times in HH:MM-HH:MM, e.g. 17:00-20:00 |
| `--businesses` | int | `15` | how many nearby businesses to check |
| `--days` | int | `14` | how many days to look ahead (booksy caps this, usually at a month) |
| `--from` | string | - | first day to look at, YYYY-MM-DD (default today) |
| `--geo` | string | - | search around LAT,LNG |
| `--limit` | int | `10` | at most this many slots in total (0 for all) |
| `--near` | string | - | search around a place: "Valencia", "Calle Mayor 1, Madrid" |
| `--per-business` | int | `1` | at most this many slots from each business |
| `--treatment` | int | `0` | catalogue treatment id (see `booksy treatment search`) |
| `--weekdays` | string | - | only these days: mon,tue,... or 1-5 (1 is Monday) |
| `--when` | stringArray | `[]` | per-day schedule, repeatable: "mon-fri 16:00-close", "sat", "2026-12-24 10:00-12:00", "2026-12-31 off" |
