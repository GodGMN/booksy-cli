## `booksy book`

Book an appointment

```bash
booksy book <business> [flags]
```

Book one service at one start time, through the same draft flow as the
booking widget. The booking is shown and confirmed before it is made; pass --yes
to skip the prompt, or --dry-run to stop just before booking.

Pick the time with --at, or --first for the earliest slot that matches the
slot filters (--days, --between, --weekdays, --before, --staff).

Booking needs a login (`booksy auth login`); --dry-run does not.

A business with no-show protection gets its cancellation fee guaranteed by the
default card saved on the account (add one on booksy.com); nothing is charged
unless you cancel late or do not show up. Prepayments are refused: pay those on
booksy.com or in the app.

```bash
booksy book 3349 --service corte --at 2026-10-30T18:00
booksy book 3349 --service 273164 --staff Javier --first --between 17:00-20:00 --dry-run
booksy book 3349 --service corte --at "2026-10-30 18:00" --note "primera vez" --yes
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--at` | string | - | start time, 2026-10-30T18:00 (business local time) |
| `--before` | string | - | only slots starting before this date or date and time |
| `--between` | string | - | only start times in HH:MM-HH:MM, e.g. 17:00-20:00 |
| `--days` | int | `14` | how many days to look ahead (booksy caps this, usually at a month) |
| `--dry-run` | bool | `false` | prepare and show the booking, then stop |
| `--first` | bool | `false` | book the earliest slot matching the slot filters |
| `--from` | string | - | first day to look at, YYYY-MM-DD (default today) |
| `--note` | string | - | note for the business |
| `--service` | string | - | variant id, service id, or part of the service name |
| `--staff` | string | - | staffer id or name (default: anyone) |
| `--weekdays` | string | - | only these days: mon,tue,... or 1-5 (1 is Monday) |
| `--when` | stringArray | `[]` | per-day schedule, repeatable: "mon-fri 16:00-close", "sat", "2026-12-24 10:00-12:00", "2026-12-31 off" |
| `--yes` | bool | `false` | book without asking |
