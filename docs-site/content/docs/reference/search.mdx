## `booksy search`

Search businesses by keyword, category and place

```bash
booksy search [query...] [flags]
```

Search businesses the way booksy.com does. The query matches business and
service names ("barberia", "uñas", "masaje"). Results centre on --near or
--geo, else the profile's saved location, else the whole country.

```bash
booksy search barberia --near Valencia --format pretty
booksy search --category 45 --geo 40.4168,-3.7038 --sort distance
booksy search "corte de pelo" --limit 50 --format jsonl | jq -r .name
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--anywhere` | bool | `false` | ignore the profile's saved location and search the whole country |
| `--category` | int | `0` | category id (see `booksy category list`) |
| `--geo` | string | - | search around LAT,LNG |
| `--limit` | int | `20` | results per page |
| `--near` | string | - | search around a place: "Valencia", "Calle Mayor 1, Madrid" |
| `--page` | int | `1` | page number |
| `--sort` | string | - | score (default) or distance |
