## `booksy slots`

Open start times for one service

```bash
booksy slots <business> [flags]
```

List the start times Booksy would offer for a service, the same list the
booking widget shows. No login needed.

--service takes a variant id (from `booksy business services`), a service id when the
service has a single variant, or part of the service name.

```bash
booksy slots 3349 --service corte --format pretty
booksy slots 3349 --service 273164 --staff Javier --days 14 --between 17:00-20:00
booksy slots 3349 --service corte --weekdays sat --first
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--before` | string | - | only slots starting before this date or date and time |
| `--between` | string | - | only start times in HH:MM-HH:MM, e.g. 17:00-20:00 |
| `--days` | int | `7` | how many days to look ahead (booksy caps this, usually at a month) |
| `--first` | bool | `false` | only the earliest matching slot |
| `--from` | string | - | first day to look at, YYYY-MM-DD (default today) |
| `--service` | string | - | variant id, service id, or part of the service name |
| `--staff` | string | - | staffer id or name (default: anyone) |
| `--weekdays` | string | - | only these days: mon,tue,... or 1-5 (1 is Monday) |
| `--when` | stringArray | `[]` | per-day schedule, repeatable: "mon-fri 16:00-close", "sat", "2026-12-24 10:00-12:00", "2026-12-31 off" |
