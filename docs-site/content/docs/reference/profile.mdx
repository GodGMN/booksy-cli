## `booksy profile`

Several accounts or countries side by side

## `booksy profile list`

Known profiles; * marks the default

```bash
booksy profile list
```

## `booksy profile remove`

Forget a profile, its login and its watches

```bash
booksy profile remove <name> [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | bool | `false` | do not ask |

## `booksy profile use`

Make a profile the default

```bash
booksy profile use <name>
```
