## `booksy business`

Inspect a business: details, services, staff, reviews, hours

Every business subcommand takes a numeric id or a booksy.com business URL,
for example https://booksy.com/es-es/3349_barberia-cavalieri-estudios-12_barberia_53009_madrid.

## `booksy business hours`

Opening hours

```bash
booksy business hours <business>
```

## `booksy business open`

Print the business's booksy.com URL

```bash
booksy business open <business>
```

## `booksy business reviews`

Customer reviews, newest first

```bash
booksy business reviews <business> [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--limit` | int | `10` | reviews per page |
| `--page` | int | `1` | page number |
