## `booksy auth`

Import, inspect or forget a booksy.com login

## `booksy auth login`

Import your booksy.com login from browser cookies

```bash
booksy auth login [flags]
```

booksy.com keeps your login in a cookie named identity-\<country> (identity-es
in Spain). Log in on booksy.com in your browser, then give the CLI one of:

  - a cookie export: Cookie-Editor or EditThisCookie JSON, a Netscape
    cookies.txt, or a copied Cookie: header (--cookies FILE, or - for stdin)
  - the bare value of the identity-\<country> cookie, pasted at the prompt

Only booksy.com cookies are read, so a whole-browser export is fine. Email,
Google, Apple and Facebook logins all end in the same cookie. The login is
checked against Booksy before it is saved to credentials.toml (mode 0600).

```bash
booksy auth login --cookies ~/Downloads/booksy-cookies.json
pbpaste | booksy auth login --cookies -
booksy auth login --country pl --profile poland
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--cookies` | string | - | cookie export file, or - for stdin |
| `--cookies-format` | string | `auto` | auto, json, netscape or header |
| `--cookies-stdin` | bool | `false` | read the cookie export or token from stdin |

## `booksy auth logout`

Forget the saved login (booksy.com stays logged in)

```bash
booksy auth logout [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | bool | `false` | do not ask |

## `booksy auth status`

Show the profile's login; --check asks Booksy if it still works

```bash
booksy auth status [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--check` | bool | `false` | verify the login against Booksy |
