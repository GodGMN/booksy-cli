---
title: booksy-cli
description: Find, watch and book Booksy appointments from the terminal. JSON by default.
---

Booksy has no public API: booking happens on booksy.com or in its app. `booksy` is one Go binary that talks to the same web API booksy.com uses, with your own account, and turns it into noun-verb commands that print JSON.

```bash
booksy earliest barba --near Valencia --when "mon-fri 16:00-close" --when sat --format pretty
```

```bash
curl -fsSL https://booksy.gimeno.dev/install.sh | sh
```

- **Search** businesses around any place, and read their services, staff, hours and reviews.
- **Open slots** for a service, filtered by your real schedule: `--when "mon-fri 16:00-close" --when sat`.
- **The earliest slot anywhere:** the same kind of service compared across nearby businesses.
- **Watch for cancellations** and get a phone notification when an earlier slot opens.
- **Book, reschedule and cancel** from your own account, always with a summary and a confirmation first.
- **Made for scripts and AI agents:** stable exit codes, machine-readable errors, `--dry-run`, and a usage guide built into the binary.

No login is needed to search, check slots or watch.
